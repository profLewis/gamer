# Contributors

Everyone here is thanked on the game's **About** page (long-press the picture on the
title screen). The game reads [`contributors.json`](contributors.json) from this
repository once a day, so this list can grow without a new release.

## How to get on the list

Anything that makes the game better counts:

- **Suggest a puzzle** — Settings > Puzzles > Suggest a Puzzle opens a pre-filled
  issue. Accepted puzzles go into the next signed puzzle pack, and their author
  is thanked here.
- **Report a bug** — the in-game bug report (Adventure Log > Report a Bug) packs
  up the save and what happened, which makes a fix far more likely.
- **Send a fix or an idea** — open an issue or a pull request.

Add yourself in the same pull request as your change: a row in the table above,
and an entry in `contributors.json` (keep the two in step — the game reads the
JSON, people read the table).
