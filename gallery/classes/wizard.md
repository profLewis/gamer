| Stat | Value |
|------|-------|
| Hit Die | d6 |
| Primary Ability | INT |
| Starting HP | 6 + CON mod |
| Armour | None |
| Weapons | Daggers, darts, quarterstaffs |

## Class Feature
**Arcane Recovery** — Recover spell slots on short rest.

## Spells
**Cantrips:** Fire Bolt (1d10 fire), Ray of Frost (1d8 cold), Shocking Grasp (1d8 lightning).

**Level 1:** Magic Missile (3d4+3, auto-hit), Burning Hands (3d6, AoE), Sleep (5d8 HP unconscious).

## Recommended Races
High Elf, Rock Gnome, Tiefling (INT bonuses).
