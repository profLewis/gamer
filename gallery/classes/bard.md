| Stat | Value |

| Hit Die | d8 |

| Starting HP | 8 + CON mod |
| Armour | Light armour |
| Weapons | Simple weapons, hand crossbows, rapiers, shortswords |

## Class Feature
**Play a Tune** — In conversation, a Bard can perform for an NPC: a Performance roll earns tips, once per audience. Also +2 to haggling. 3 skill proficiencies.

## Spells
**Cantrips:** Vicious Mockery (1d4 psychic, WIS save — an insult so cutting it hurts).

**Level 1:** Healing Word (1d4 + CHA mod healing, bonus action), Sleep (5d8 HP unconscious).

**Level 2 (learned at level 3):** Shatter (2d8 thunder to all enemies, CON save for half).

## Recommended Races
Half-Elf, Tiefling, Lightfoot Halfling (CHA bonuses).
