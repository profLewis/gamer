# Rock Gnome

| Trait | Value |
|-------|-------|
| Ability Bonuses | +2 INT, +1 CON |
| Speed | 25 ft |
| Size | Small |

## Racial Traits
- Darkvision
- Gnome Cunning (advantage on INT/WIS/CHA saves vs magic)
- Tinker's Tools proficiency

## Recommended Classes
- Wizard (INT bonus + magic saves)
- Any class (Gnome Cunning is universally useful)
