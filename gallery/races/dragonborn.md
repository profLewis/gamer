# Dragonborn

| Trait | Value |
|-------|-------|
| Ability Bonuses | +2 STR, +1 CHA |
| Speed | 30 ft |
| Size | Medium |

## Racial Traits
- Breath Weapon (2d6 damage, scales with level)
- Damage Resistance (matches breath type)

## Recommended Classes
- Fighter (STR + breath weapon)
- Barbarian (STR)
- Any melee class
