# Lightfoot Halfling

| Trait | Value |
|-------|-------|
| Ability Bonuses | +2 DEX, +1 CHA |
| Speed | 25 ft |
| Size | Small |

## Racial Traits
- Lucky (reroll nat 1s)
- Brave (advantage vs frightened)
- Halfling Nimbleness (move through larger creatures)
- Naturally Stealthy

## Recommended Classes
- Rogue (DEX + stealth + lucky)
- Ranger (DEX)
- Bard (CHA)
