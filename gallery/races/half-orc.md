# Half-Orc

| Trait | Value |
|-------|-------|
| Ability Bonuses | +2 STR, +1 CON |
| Speed | 30 ft |
| Size | Medium |

## Racial Traits
- Darkvision
- Menacing (Intimidation proficiency)
- Relentless Endurance (drop to 1 HP instead of 0 once per long rest)
- Savage Attacks (extra crit die)

## Recommended Classes
- Barbarian (STR + Savage Attacks + Relentless)
- Fighter (STR + tough)
- Any melee class
