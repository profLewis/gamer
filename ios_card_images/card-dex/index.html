About DnDex

DnDex is a visual card browser for the default iOS game content: core character names, dungeon locations, and monsters. It presents the generated cards in one place for browsing, comparison, sharing, and download.

In the game itself, you can define your own names for characters and other elements during setup and through gameplay choices. The cards here reflect the default reference set.
